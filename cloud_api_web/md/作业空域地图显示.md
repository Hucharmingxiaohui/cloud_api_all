# 作业空域地图显示

2026-11-16：依据用户提供的14个边界点，按1至14顺序闭合显示，标注“真高300米以下”。原文未注明大地坐标系，目前按WGS84录入，显示时沿用平台WGS84转GCJ-02函数；若批复采用其他坐标系，需先核实转换再使用。

- 二维设备地图及施工区域、线路、巡检计划使用的公共二维地图显示独立的金色虚线边界和编号。
- 地图左下角可开关空域显示，点击“查看全域”定位完整边界。保留原机巢初始视角。
- 配置位于 `public/config.js` 的 `flightAirspace`，经度在前、纬度在后，`enabled: false` 关闭图层。部署时更新前端构建产物及服务器的 `config.js`；若保留服务器配置，须合并该字段，勿覆盖服务器接口地址。
- 图层不写入施工区域表，不改变既有区域、线路、计划或航线高度，不进行飞行围栏或高度拦截。真高说明不等同于椭球高或相对起飞点高度设置。
- 检查脚本：`node scripts/test-flight-airspace.cjs`，核对全部度分秒转换、经纬度顺序、一次坐标转换、开关、全域定位及销毁清理。
