# 区域内自动生成 S 型航线

更新日期：2026-11-03。

## 使用方法

进入“变量管理 → 施工区域 → 选择工作面 → 区域航线 → 二维新建”。先在编辑器左上方选择一座具有有效实时椭球高的**参考机巢**，再点击 **自动生成 S 型航线**，填写参数，点击“计算航线”查看扫描线数、总航点数、拍照点数和路线长度，再点击“应用到编辑器”。地图显示生成结果，可继续拖动航点、调整参数和动作；检查后点击原有“提交”保存。

当前已有航点时会确认是否替换草稿，取消保留原航点。应用生成结果不会覆盖已经保存的航线，也不会下发飞行。保存沿用原有区域航线接口、工作面关联及统一航线库。

| 参数 | 初始值 | 说明 |
| --- | --- | --- |
| 航线方向 | 0° | 0为南北向，90为东西向，可填0～179°；相邻行反向飞行 |
| 扫描行间距 | 20m | 平行扫描线间距上限，窄分支可能补充扫描线 |
| 沿线拍照点间距 | 20m | 扫描线内等分布点，实际间距不超过设置值；连接段不保证同样间距 |
| 相对机巢航高 | 100m | 用于生成时计算绝对航高：`参考机巢 WGS84 椭球高 + 此值`；不是地形跟随高度 |
| 速度 | 5m/s | 航线飞行速度 |
| 云台俯仰 | −90° | 镜头垂直向下，可填−90～0°；机头默认沿航线方向 |
| 镜头 | 可见光广角 | 可选红外、可见光+红外，须匹配实际设备能力 |
| 安全起飞高度 | 20m | 在二维编辑器“执行高度”卡片中设置；相对起飞点，用于起飞至首航点前的最小安全爬升高度，范围2～1500m |

初始值仅方便生成预览，尚未按现场相机和高度校验照片覆盖率。扫描线铺设不等于照片无遗漏；实际覆盖取决于镜头视场、拍照间距、高度及倾角。本功能不进行障碍物、地形或禁飞区判断。

### 高度基准与执行机巢

- 生成 S 型航线时，参考机巢只用于读取当时的 `basic_osd.height`（WGS84 椭球高）并完成一次换算。KMZ 中写入 `executeHeightMode=WGS84`，全局高度和各航点执行高度均为换算后的绝对椭球高。
- 示例：参考机巢椭球高为100m、填写相对机巢航高30m，生成后的航点执行高度为130m WGS84。
- 航线保存后高度已经写死，**不绑定参考机巢**；可在创建工地巡检计划时选择任意属于当前工作空间的执行机巢。
- 安全起飞高度与WGS84航点绝对高度是独立参数。现场应结合机巢周边障碍物、起飞路径和首航点高度设置安全起飞高度；本功能不会自动进行避障或地形跟随。
- 旧的 `relativeToStartPoint` 相对高度航线不能用于创建新的工地巡检计划，须以当前方式重新生成WGS84航线。

## 生成和拍摄规则

- 使用局部米制坐标计算扫描线与多边形交点，保存仍为WGS84。支持矩形、三角形及简单凹多边形，不支持带孔、多片独立区域。
- 扫描线交替方向组成往返航线；凹形区域中，连接线如会越界，则通过区域边界顶点寻找区域内连接路径。最终再次校验所有航点和航段。
- 扫描线航点采用到点停、先旋转云台再拍照；额外转场点标注“转场”，只调云台，不拍照。每个拍照点使用“航点”加实际序号的照片后缀。
- 生成后编辑航点时保留拍照镜头和命名参数；工地航点移除全部动作后不继续保留旧拍照动作。修改拍摄俯仰时请检查航点动作中的“云台俯仰角”，它是到点拍照前执行的角度。
- 二维地图以编号圆点显示工地航点，并在圆点上方显示机头航向箭头。沿航线方向时箭头指向下一航点；手动控制或自定义偏航时箭头按设定角度显示；最后一个航点沿上一航段显示。航段中的黄色箭头仅作稀疏方向提示，避免密集S型航线遮挡底图。
- 最多2000航点、200个区域顶点，区域跨度限20公里；超限或无法在区域内连接时明确报错，不应用部分结果。行距和点距支持1～1000米。

## 后端与部署

前端在现有编辑器中生成普通航点，保存仍走既有 `POST /api/construction/areas/{areaId}/waylines`。本轮没有新增数据库表或SQL迁移。

后端 `CreateWpml` 修正首航点额外归零逻辑：当航点动作已明确包含 `gimbalRotate` 时，不再额外插入俯仰0°动作，避免自动生成的−90°在拍照前被覆盖。没有显式云台旋转动作的既有航线保留原逻辑。

**需要同时更新前后端**，仅更新前端无法获得本轮执行文件的角度修正和WGS84高度模式校验。无需执行新SQL。
