# 工地巡检菜单模式

在前端运行配置 `public/config.js` 中设置：

```js
constructionOnly: true,
```

默认值为 `false`，不填写时也保持现有完整菜单。只有布尔值 `true` 开启，不要写成字符串 `'true'`。

开启后隐藏以下菜单：

- 变量管理 → 风机管理。
- 变量管理 → 光伏管理及其全部子菜单。
- 点位管理。
- EUA设备监控。
- 任务管理 → 光伏板计划、风机计划、EUA飞行计划。

施工区域、工地巡检计划、总体航线入口、飞行任务、设备管理、航线管理、视频直播及其他未指定的菜单保持原样。本开关按本次明确指定的菜单隐藏，不会把所有非工地页面都移除。

本功能控制菜单展示，不删除路由、历史任务或数据库记录，也不作为接口权限控制。直接输入已有页面地址仍可访问。

首次使用需部署包含本次修改的新前端文件；无需部署后端或修改数据库。此后只需编辑前端部署目录下的 `config.js`，修改开关并强制刷新浏览器（Ctrl+F5）。设置为 `false` 并刷新即可恢复原菜单。

系统标题仍通过同一文件中的 `sysName` 单独配置。
