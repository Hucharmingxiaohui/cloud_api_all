# 车载驻车点标定

更新时间：2026-10-29。

## 操作流程

1. 打开 **变量管理 → 施工区域**，地图上方新增“车载驻车点”工具栏。
2. 点击 **标定驻车点**，填写名称，在地图单击位置，设置覆盖半径后保存。支持100米、2公里、5公里快捷值，以及100～5000米整数自定义半径。
3. 点击地图上的 **P标记**，或从下拉列表选择驻车点。选中点显示紫色脉冲动效和覆盖圈，下方列出完全覆盖、部分覆盖的工作面；点击工作面名称可定位该区域。
4. 有多个机巢时，在地图顶部选择当前机巢；只有一个有有效定位的机巢时可自动用于距离显示。选中驻车点后显示机巢到驻车点的虚线，以及地图和工具栏中的直线距离。机巢位置更新后连线与距离同步更新。
5. 通过 **编辑** 修改名称、半径或重新地图选点；**取消** 放弃本次编辑；**删除** 经确认后移除驻车点。刷新页面后已保存的驻车点仍在，默认不自动选中。

## 数据含义

- 驻车点是预设位置，不会覆盖机巢实时位置，也不会修改当前机巢的已保存覆盖半径、计划下发条件或航线。
- 坐标按WGS84保存，地图显示转换为地图坐标；距离使用WGS84经纬度计算球面距离，显示米或公里，不是道路导航里程，不含高差。
- 覆盖工作面以当前页面已加载的区域为准，因此会受搜索、状态和归档筛选影响；完整在圈内标记“完全覆盖”，仅部分相交标记“部分覆盖”。
- 没有机巢定位时仍可标定驻车点、查看覆盖范围；不会生成虚假的连线或距离。多个机巢但尚未选择时提示选择。
- 所有驻车点按登录工作空间隔离，保存在当前部署端数据库。两套部署可使用相同功能；本轮不增加驻车点跨端同步或部署类型开关。
- 标定和区域边界编辑分开操作，编辑区域时驻车点选点入口禁用。

## 部署

本轮需同时更新前后端。先在平台使用的数据库执行后端 `sql/20261029_construction_parking.sql`，创建 `construction_parking_point`，再构建部署前后端。

配置字段包括名称、经纬度、半径和版本。新增内部接口：

| 请求 | 用途 |
| --- | --- |
| GET `/api/construction/parking-points` | 当前工作空间驻车点列表 |
| POST `/api/construction/parking-points` | 新建，提交name、lng、lat、radius_m |
| PUT `/api/construction/parking-points/{id}` | 更新，上述字段加version |
| DELETE `/api/construction/parking-points/{id}?version=…` | 按版本删除 |

版本冲突时拒绝覆盖，重新加载后操作。坐标须为有限数值，经度-180～180，纬度-85～85；半径须为100～5000米整数，名称1～80字符。
