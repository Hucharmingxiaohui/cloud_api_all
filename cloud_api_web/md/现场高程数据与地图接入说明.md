# 现场高程数据与地图接入说明

更新：2026-11-16。

## 当前完成状态

已接入前端 GeoTIFF 查询、地图单点查椭球高和航线剖面复核。施工区域/线路的已绑定航线、总体航线及计划地图共用剖面入口；施工区域 S 型航线编辑器也可复核草稿。二维卫星地图不变，测距仍是水平距离，三维地形及测距端点高差未实现。

| 文件 | 内容 |

高程文件是带地理定位信息的数值栅格，不是卫星影像PNG。成果为829列×723行，共599367个Float32高度值，单位米；约30米格网，标注EPSG:4979（WGS84三维坐标）。范围约东经103.48—103.71、北纬24.65—24.85，含像元对齐边缘，覆盖用户提供的全部14个空域边界点。

原始数据目录仍忽略 Git；用于平台的约2.4MB裁剪成果已复制到 `public/terrain/shilin-ellipsoid.tif`，附转换报告和来源说明，随构建自动进入 `dist/terrain`。无需将40MB原始数据及全球转换模型部署到服务器。

## 高度含义和转换

按每个格网点计算 `h = H + N`：H为原EGM2008高程，N为该点EGM2008大地水准面起伏，h为WGS84椭球高。N通过原模型点格网双线性插值获得，不使用全区域统一常量。保留原DEM采样点和RasterPixelIsPoint定位，不增加原数据精度。

成果高度约1782.31—2362.67米，转换使用的N约−31.77—−31.36米；这些是该裁剪矩形的栅格统计，不是设备实测高度或空域限高。原数据为DSM，可能包含树冠和建筑，不能自动视为裸地DTM。“真高300米以下”、椭球高及相对起飞点高度是不同概念，当前没有用这份数据修改航线或执行限高判断。

## 展示方式与完成状态

| 方式 | 展示效果 | 接入要求 |
| --- | --- | --- |
| 二维点击查高（已实现） | 点击“查椭球高”，地图选点显示地表椭球高 | GCJ-02转换WGS84后查询；覆盖外、NoData和读取失败明确提示 |
| 测距增加高度 | 起点、终点高度和高差，与原水平距离分别显示 | 共用高程查询，不把水平距离直接改称三维距离 |
| 航线高程剖面（已实现） | 航线/地表椭球高、净空估算和疑似穿地/低净空/高差上限提示 | 航段加密采样，保留所有航点，标明实际间距和未知段；滑块选取采样点，已绑定航线可定位地图 |
| 三维地形查看 | 倾斜、旋转查看起伏地形，并叠加卫星影像及业务图层 | 接入适配的三维引擎视图，将高程转换为地形瓦片并核对影像与地形坐标 |

当前二维地图不会因下载了GeoTIFF而自动变成三维地形。可保留现有二维业务页面，后续另设三维查看入口；是否复用项目已有三维组件需实施时检查。约30米格网用于整体地形展示，不会生成精细建筑、电杆和导线模型。

## 使用与部署

`public/config.js`（部署后为 `dist/config.js`）新增：

```js
terrainElevation: { enabled: true, url: '/terrain/shilin-ellipsoid.tif' },
```

默认从前端同源读取 `dist/terrain`，普通静态站点配置即可。使用子路径部署需修改URL；本地开发若想读服务器文件可填完整URL，服务器需允许该开发来源的CORS。修改后刷新页面。若服务器保留旧config文件，合并上述配置并拷贝terrain目录。返回index.html而非TIFF、404、超时均显示高程不可用，不使用零值兜底。

1. 地图右下“查椭球高”后单击地图；“清除”移除结果。与测距共用选点模式，业务编辑期间禁止抢占选点。
2. 选择有效航线，点击“航线高程 / 剖面复核”；S型草稿生成后在编辑器地图上方同样可展开。
3. WGS84模式直接使用已存航线高度，不随机巢实时高度变化。`relativeToStartPoint`必须手动输入并核实**原航线起飞点椭球高**；不以首点地表或当前机巢高度自动代替。未知模式不推断。
4. 默认低净空提示30米、高差上限提示300米，可临时调整。所有提示只供复核，不写入任务、航线或算法配置。高差是航线椭球高减DSM椭球高，不能直接作为真高300米空域合规结论。重复同一位置的不同航段分别计数。
5. 通常按不超过25米间距采样，长航线自动加大间距并显示实际数值，最多约6000点；缺测区间断开，不跨缺测段补高。只有高度值有效且覆盖已知时才显示高差。

## S型航线1500米修正

前端计算、全局/单航点控件与后端创建校验曾把WGS84绝对高度误限为2—1500米。已去掉这一绝对高度区间，校验有限数值；保留相对机巢航高1—1500米及原返航高度约束。例：机巢2029.7882 + 相对100 = 航线2129.7882米，KMZ保存值保持一致，不做限幅。

本次需要同时更新前后端；没有数据库迁移，不修改已标注区域与已有航线。以前生成或保存的错误高度不会被自动纠正，请重新生成并复核后保存。
