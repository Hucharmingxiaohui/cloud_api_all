# 地图两点测距

2026-11-16：设备二维地图和施工区域、线路、计划共用的二维地图新增“测距”。

1. 点击地图右下角“测距”。
2. 依次点击起点、终点，显示起终点标记、直线及水平距离。小于1千米以米显示，否则显示千米。
3. 点击“重新测距”重新选点；点击“清除”移除结果；选点中可按Esc取消。

测量完成后恢复地图交互。施工区域、线路、驻车点编辑时需先结束编辑再测距。测量采用地图坐标转WGS84后的球面距离，不包含高差、地形或绕行距离，仅临时展示，不写入业务数据。

仅需更新前端，无后端或数据库变更。检查脚本：`node scripts/test-map-distance.cjs`。

另有“查椭球高”按钮，可单独查询一个位置的地表椭球高。测距本身仍不包含端点高度或高差。航线高程与剖面复核、部署方法见[现场高程数据与地图接入说明](现场高程数据与地图接入说明.md)。
