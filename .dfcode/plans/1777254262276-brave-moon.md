# 光伏区绘制组件修改计划

## Context
用户要求修改 `solarDraw.vue` 组件的两处行为：
1. 保存时自动将选中的正射图 name 作为 `solar_area_name`，不再在右侧表单中手动输入
2. 导入正射图时，名称不能与已有列表中的 name 重复

## Approach
直接在 `solarDraw.vue` 中进行最小改动：
- 移除右侧参数表单中的 `光伏区域名称` 输入项
- 在 `saveDetectionAreas` 函数中，将 `currentImageInfo.value.name` 直接赋给 `solar_area_name`
- 在 `confirmImport` 函数中增加 name 重复校验逻辑

## Implementation Steps
1. 移除右侧 `param-panel` 中的 `光伏区域名称` `el-form-item`（约第220-222行）
2. 移除 `paramForm` 响应式对象中的 `solar_area_name` 字段及保存函数中对其的手动校验（约第92-95行）
3. 修改 `saveDetectionAreas`，将 `solar_area_name` 的来源改为 `currentImageInfo.value.name`
4. 修改 `confirmImport`，在提交前遍历 `orthophotoList.value`，检查 `name` 是否已存在，若存在则提示并不再提交
5. 重置表单时同步去掉 `solar_area_name` 的清空逻辑
